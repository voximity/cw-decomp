# Analysis outputs

Generated by the scripts in `tools/`. Regenerate in this order with the Ghidra MCP server stopped:

```
export GHIDRA_INSTALL_DIR=/opt/homebrew/opt/ghidra/libexec
.venv/bin/python -P tools/ghidra_export.py game/Server.exe game/Cube.exe
.venv/bin/python tools/rtti_dump.py game/Server.exe game/Cube.exe
.venv/bin/python tools/classify.py analysis/export/Server.exe.json analysis/export/Cube.exe.json --sqlite-literals <path to sqlite 3.7.15 literals>
.venv/bin/python tools/match_functions.py --dump <scratch>/matches.json
.venv/bin/python tools/carry_tags.py <scratch>/matches.json
.venv/bin/python -P tools/ghidra_apply_tags.py game/Server.exe game/Cube.exe
```

| Directory | Contents |
|---|---|
| `export/` | Per-binary JSON: every function with callees, external calls, string and data references; all strings; classes; vtables; imports |
| `rtti/` | Class hierarchy and vtables recovered from MSVC RTTI in the PE itself, as JSON and as a Markdown tree |
| `tags/` | Classification of every function with a confidence and the reason, mirrored into Ghidra as function tags |
| `project/` | The Ghidra project. Not committed. |

The Cube.exe column includes the post-pass `tools/carry_tags.py` (2026-09-23): for every Server.exe/Cube.exe pair from `tools/match_functions.py --dump` with confidence >= 0.9 where the Cube.exe tag was `unknown` or `crt` and the Server.exe tag more specific, Cube.exe takes the Server.exe tag (confidence `derived`, reason `matched Server.exe 0x... (conf N)`). That moved 245 functions: 164 `unknown` -> `cube`, 74 `crt` -> `cube`, 7 `unknown` -> `sqlite`. Server.exe tags are unchanged. **The Ghidra function tags for Cube.exe are stale** until `tools/ghidra_apply_tags.py game/Cube.exe` is re-run with the Ghidra MCP server stopped.

Exception-handling fragments are Ghidra's unwind and catch funclets, counted as functions but not code to read. Excluding `eh` and `thunk`, the real function counts are Server.exe 2673, Cube.exe 5848.

Known gaps: `unknown` in Cube.exe is mostly engine internals that have neither a vtable nor a string; the reachability rule only runs for the self-contained libraries. FreeType looks smaller than a full static link, so the client may carry only a subset or the remainder sits in `unknown`. Vtable method counts in `rtti/` can differ by one or two from Ghidra's where a table runs into unlabeled data.
